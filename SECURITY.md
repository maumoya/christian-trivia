# Security policy

## Reporting a vulnerability

If you find a problem, for example a way the page could run code it should not or send data anywhere,
report it privately through GitHub's
[private vulnerability reporting](https://github.com/maumoya/christian-trivia/security/advisories/new).
You will get an answer within 7 days.

## What the game promises

- One static HTML file. No accounts, no ads, no analytics, no data sent anywhere.
- Fonts load from Google Fonts. Progress and settings stay in your browser (localStorage).
- The parent area is behind a simple adult check.

## Supported versions

Only the latest release is supported.
